I created my own Tetris-style game that takes the original idea and adds more variety to the gameplay. I added new shapes that differ from the traditional pieces, along with multiple game modes that offer players different ways to play. I also made the gameplay faster-paced so that the game becomes more challenging as you continue playing. While working on this project, I practiced my programming and problem-solving skills, especially in moving the pieces correctly, detecting completed lines, keeping track of the score, and implementing the different game modes. This project challenged me to think about both how the game works behind the scenes and how to make the game fun for the player. Creating this game helped me become more comfortable with programming and gave me more experience building a complete project from my own ideas.
